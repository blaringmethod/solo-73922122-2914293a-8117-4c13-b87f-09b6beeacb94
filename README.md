# 手摇音乐盒 · 纸带续排

手摇音乐盒改谱时，纸带上已经打过的孔要接着用。本工具在改谱或补记打孔后重新排样：
每个音符组整体前后至多挪一格，给出**各组挪动格数之和最小**的排法，并列出还要打的孔。

## 功能

- 录入纸带格数、同音孔最小间距、最多 16 组音符（同一拍格的音算一组）；
- 实际打出的孔可随时补记（可批量、可删误记），曲谱与打孔记录存入 SQLite；
- 改谱 / 补记 / 删孔 / 改参数后自动重排（也可手动「立即重排」）；
- 排样约束：各组保持原顺序、各占不同拍格；孔位在纸带内；满足同音孔最小间距；
  **全部已打孔都必须用上**（已打孔是最终孔位的子集）；
- 输出每组挪动量、总挪动格数（最小）、还要打的孔（按格分组）、沿用的已打孔；
- 无解时提示原因，**收起旧排样**（折叠展示、标注勿用），打孔记录保留。

## 快速开始（Docker Compose）

```bash
docker compose up --build
# 打开 http://localhost:8000
```

首次启动会写入一段《小星星》示例（含两个已打孔），设 `SEED_DEMO=0` 可关闭。
SQLite 数据保存在 `musicbox-data` 卷中。

## 本地运行

```bash
pip install -r requirements.txt
python app.py          # http://localhost:8000
```

## 输入格式

- 音符组：每行一组，`拍格: 音名1 音名2 …`，拍格严格递增、不超纸带，最多 16 行。
- 打孔补记：每行一个，`拍格 音名`（空格/冒号/逗号分隔均可），重复记录自动忽略。
- 音名：`C4`、`F#3`、`Bb5`（降号自动转等音升号），或 0-127 的 MIDI 音高数字。

## 求解方法

按组顺序动态规划：每组候选落位为原拍格 ±1（且在纸带内、能用上落点处全部已打孔），
状态记录最近 `min_spacing-1` 组的落位用于检查同音孔距（位置严格递增时，
下标差 ≥ 孔距的两组位置差必然 ≥ 孔距，无需再往前看），转移时保证
相邻落位之间不夹着用不上的已打孔；目标为各组挪动格数之和最小。

## 已知限制

- 同音孔最小间距限 1～8（求解状态数随孔距指数增长；音乐盒实际孔距通常为 2～4）。
- 等音只按名称规范化（如 `Db4`→`C#4`），未做 MIDI 与音名互通换算。
- 单进程 Flask 开发服务器，演示用途；生产可换 gunicorn 并设置 `SECRET_KEY`。
